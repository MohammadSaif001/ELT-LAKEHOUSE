# Data Catalog for Gold Layer

## Overview

The Gold layer is the business-level representation of the ELT Lakehouse. It
contains dimensional and fact tables for analytical queries, reporting, and
downstream serving.

Gold models are implemented in [`dbt_gold/`](../dbt_gold/) and built with:

```bash
uv run python scripts/run_gold_dbt.py
```

The build reads validated Silver Delta tables and writes Gold Delta tables
under `storage/gold/`.

## Model overview

| Table | Type | Grain | Primary key |
| --- | --- | --- | --- |
| `gold.dim_customer` | Dimension | One row per customer ID | `customer_key` |
| `gold.dim_seller` | Dimension | One row per seller ID | `seller_key` |
| `gold.dim_product` | Dimension | One row per product ID | `product_key` |
| `gold.dim_location` | Dimension | One row per ZIP-code prefix | `zip_code_prefix` |
| `gold.dim_date` | Dimension | One row per calendar date | `date_key` |
| `gold.dim_review` | Dimension | One row per review | `review_id` |
| `gold.fact_order_items` | Fact | One row per order item | `order_id` + `order_item_id` |
| `gold.fact_orders` | Fact | One row per order | `order_id` |
| `gold.fact_seller` | Periodic fact | One row per seller per month | `seller_key` + `month` |
| `gold.fact_product` | Periodic fact | One row per product per month | `product_key` + `month` |

---

## 1. `gold.dim_customer`

- **Purpose:** Stores customer identity and location attributes used to
  analyze orders and customer activity.
- **Source:** `silver.customers_silver`

| Column name | Data type | Description |
| --- | --- | --- |
| `customer_key` | BIGINT | Deterministic Spark `xxhash64` surrogate key for `customer_id`. |
| `customer_id` | STRING | Customer identifier from the source system. |
| `customer_unique_id` | STRING | Identifier that groups customer records belonging to the same person. |
| `customer_zip_code_prefix` | STRING | Customer ZIP-code prefix. |
| `customer_city` | STRING | Customer city. |
| `customer_state` | STRING | Customer state or region code. |

## 2. `gold.dim_seller`

- **Purpose:** Stores seller identity and location attributes used to analyze
  seller performance.
- **Source:** `silver.sellers_silver`

| Column name | Data type | Description |
| --- | --- | --- |
| `seller_key` | BIGINT | Deterministic Spark `xxhash64` surrogate key for `seller_id`. |
| `seller_id` | STRING | Seller identifier from the source system. |
| `seller_zip_code_prefix` | STRING | Seller ZIP-code prefix. |
| `seller_city` | STRING | Seller city. |
| `seller_state` | STRING | Seller state or region code. |

## 3. `gold.dim_product`

- **Purpose:** Provides product attributes for product, category, revenue, and
  item-volume analysis.
- **Source:** `silver.products_silver`

| Column name | Data type | Description |
| --- | --- | --- |
| `product_key` | BIGINT | Deterministic Spark `xxhash64` surrogate key for `product_id`. |
| `product_id` | STRING | Product identifier from the source system. |
| `product_category_name` | STRING | Product category. |
| `product_name_length` | INT | Product-name length in characters. |
| `product_description_length` | INT | Product-description length in characters. |
| `product_photo_quantity` | INT | Number of product photos. |
| `product_weight_g` | DOUBLE | Product weight in grams. |
| `product_length_cm` | DOUBLE | Product length in centimetres. |
| `product_height_cm` | DOUBLE | Product height in centimetres. |
| `product_width_cm` | DOUBLE | Product width in centimetres. |

## 4. `gold.dim_location`

- **Purpose:** Provides one canonical location record for each ZIP-code prefix.
- **Source:** `silver.geolocation_silver`
- **Transformation:** Coordinates are averaged and the most frequent
  city/state combination is retained for each ZIP-code prefix.

| Column name | Data type | Description |
| --- | --- | --- |
| `zip_code_prefix` | STRING | ZIP-code prefix and primary key. Leading zeroes are preserved. |
| `geolocation_lat` | DOUBLE | Average latitude for the ZIP-code prefix. |
| `geolocation_lng` | DOUBLE | Average longitude for the ZIP-code prefix. |
| `geolocation_city` | STRING | Most frequently observed city for the prefix. |
| `geolocation_state` | STRING | Most frequently observed state for the prefix. |

## 5. `gold.dim_date`

- **Purpose:** Provides reusable calendar attributes for date-based reporting.
- **Source:** Generated by the Gold model; it is not read from a Silver table.

| Column name | Data type | Description |
| --- | --- | --- |
| `date_key` | INT | Date surrogate key in `YYYYMMDD` format. |
| `date` | DATE | Calendar date. |
| `year` | INT | Calendar year. |
| `quarter` | INT | Calendar quarter from 1 to 4. |
| `month` | INT | Month number from 1 to 12. |
| `month_name` | STRING | Month name. |
| `day` | INT | Day of the month. |
| `day_of_week` | INT | Day-of-week number. |
| `day_name` | STRING | Day name. |
| `is_weekend` | BOOLEAN | Whether the date falls on Saturday or Sunday. |

- **Purpose:** Stores review text associated with an order.
- **Source:** `silver.reviews_silver`

| Column name | Data type | Description |
| --- | --- | --- |
| `review_id` | STRING | Review identifier and primary key. |

| `review_comment_title` | STRING | Review title. |
| `review_comment_message` | STRING | Review text. |

## 7. `gold.fact_order_items`

- **Purpose:** Stores item-level order transactions. This is the base fact for
  seller and product performance metrics.
- **Source:** `silver.order_items_silver` joined to
  `silver.orders_silver`, `dim_product`, `dim_seller`, `dim_customer`, and
  `dim_date`.

| Column name | Data type | Description |
| --- | --- | --- |
| `order_id` | STRING | Order identifier; part of the logical primary key. |
| `order_item_id` | INT | Item sequence within the order; part of the logical primary key. |
| `product_key` | BIGINT | Foreign key to `dim_product`. |
| `seller_key` | BIGINT | Foreign key to `dim_seller`. |
| `customer_key` | BIGINT | Foreign key to `dim_customer`. |
| `order_date_key` | INT | Foreign key to `dim_date` for the purchase date. |
| `shipping_limit_date` | TIMESTAMP | Seller shipping deadline. |
| `price` | DOUBLE | Item price, excluding freight. |
| `freight_value` | DOUBLE | Freight cost for the item. |

## 8. `gold.fact_orders`

- **Purpose:** Stores one analytical record per order, including payment,
  review, delivery, and lateness metrics.
- **Source:** `silver.orders_silver` with item, payment, and review
  aggregations.

| Column name | Data type | Description |
| --- | --- | --- |
| `order_id` | STRING | Order identifier and primary key. |
| `customer_key` | BIGINT | Foreign key to `dim_customer`. |
| `order_status` | STRING | Current order status. |
| `purchase_date_key` | INT | Foreign key to `dim_date` for purchase date. |
| `approved_date_key` | INT | Foreign key to `dim_date` for approval date; nullable. |
| `carrier_date_key` | INT | Foreign key to `dim_date` for carrier handoff; nullable. |
| `delivered_date_key` | INT | Foreign key to `dim_date` for customer delivery; nullable. |
| `estimated_date_key` | INT | Foreign key to `dim_date` for estimated delivery. |
| `order_item_count` | INT | Number of items in the order. |
| `order_payment_value` | DOUBLE | Sum of payment values for the order. |
| `max_installments` | INT | Highest payment-installment count for the order. |
| `main_payment_type` | STRING | Payment type with the highest total payment value. |
| `review_score` | INT | Most recent review score for the order. |
| `delivery_days` | INT | Days between purchase and customer delivery; nullable. |
| `delivery_delay_days` | INT | Days between delivery and estimated delivery; positive means late. |
| `is_late` | INT | `1` when delivered after the estimate, `0` when not late, nullable when undelivered. |

- **Purpose:** Stores monthly seller performance metrics.
- **Source:** Aggregated from `fact_order_items` and `fact_orders`.

| `orders` | INT | Distinct orders containing the seller's items. |
| `items_sold` | INT | Number of items sold. |
| `late_rate` | DOUBLE | Share of delivered seller orders that were late. |
| `average_delivery_days` | DOUBLE | Average delivery time in days. |
| `average_review_score` | DOUBLE | Average review score. |

| Column name | Data type | Description |
| --- | --- | --- |
| `product_key` | BIGINT | Foreign key to `dim_product`. |

| `units_sold` | INT | Number of units sold. |

| `average_review_score` | DOUBLE | Average review score. |

## Keys and relationships

- `customer_key`, `seller_key`, and `product_key` are deterministic Spark
  `xxhash64` values derived from their corresponding business IDs.
- `fact_order_items` joins to dimensions through surrogate keys.
- `fact_orders` joins to `dim_customer` and `dim_date`.
- `fact_seller` joins to `dim_seller`.
- `fact_product` joins to `dim_product`.
- `fact_seller` and `fact_product` are aggregated from item-level data to
  prevent seller and product metrics from being calculated at order grain.

## Data quality and validation

Generic dbt tests are defined in
[`dbt_gold/models/schema.yml`](../dbt_gold/models/schema.yml). Custom SQL tests
are in [`dbt_gold/tests/`](../dbt_gold/tests/). They cover:

- Primary-key uniqueness and non-null constraints.
- Foreign-key relationships from facts to dimensions.
- Fact row-count preservation against Silver.
- Revenue reconciliation across item, seller, and product facts.
- Delivery metrics being null for undelivered orders.
- Continuity of the date dimension.

Because the configured dbt command is `build`, the Gold command runs models and
tests together.
