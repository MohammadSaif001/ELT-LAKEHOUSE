# Project documentation

This folder contains design and operational documentation that supplements the
root [`README.md`](../README.md).

## Sections

- `architecture/` — system and data-flow diagrams.
- `adr/` — architecture decision records explaining major technology choices.
- `lineage/` — source-to-target lineage documentation.
- `plans/` — scoped implementation plans.
- `runbooks/` — recovery and operational procedures.
- `catalog.md` — Gold model grains, keys, and table descriptions.

Update the relevant ADR or runbook when a code change alters an operational
dependency, recovery step, or data contract.
